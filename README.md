# TOUCHLINE

JavaScript + Three.js / WebGL による22人の3Dサッカーシミュレーター。

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ を生成
npm test         # 試合ロジックとアニメーションの検証
```

## 遊び方

- 8か国・3スタジアム、4-3-3 / 4-4-2 / 3-5-2、4種の戦術を両チームに個別設定
- カメラ：追従・中継・俯瞰・自由。Spaceで一時停止、1/2/4倍速、リセット、全画面、統計、ミニマップ
- 日本語実況字幕（1,000パターン、CCで切替）、天候4種、3都市の背景
- 実況と解説は別の男性2音声。主要場面では実況の直後に解説が、プレーの意味・狙いと選手やチームの背景を添える
- 1倍速＝実時間1秒で試合時間12秒。90分は約7分30秒＋再開待ち

## 選手・アニメーション

- ローポリ選手（約7頭身）。細身のシルエットに胸バンド・襟のキットデザイン。身長・体格・肌・髪型は個別生成
- 両競技とも頭部はCC0のベースモデル（Quaternius「Universal Base Characters」、クレジット参照）を選手ごとに変形して使用。首は細めに絞り、顎が首に埋まらない位置で接続。髪型はモデルの短髪・フラットトップ・クイッフ・髭の4種＋坊主（眉のみ）に、従来の11種の髪型名から割り当て
- 顎の幅・顎の出方、目の間隔・形、眉の太さ・角度、鼻の幅・高さ・位置、唇の厚み、頭蓋の幅・奥行きと肌の色は地域性のある顔タイプ（東アジア、欧州、アフリカ、ラテン、中東、南アジア）で国・チーム別に変化し、個体差のばらつきも付く
- 選手・控え・監督の髪色は20〜30代前提でグレー・白髪なし。審判だけはグレー〜白髪を許可
- 選手名は漢字・カタカナ併記（例：高橋 蓮（タカハシ・レン） / Ren Takahashi）
- 速度連動の歩幅・接地、膝・足首・肘、体幹前傾。加減速で体幹が前後に傾き、方向転換では内側にバンクする。腕振りは脚より少し遅れて追従する
- 静止時は呼吸・体重移動などのアイドルモーション
- 競り合い、トラップ、ヘディング、ファウル転倒、キーパー（構え・ダイビング・キャッチ）、得点後はコーナーへ走る得点演出＋ダイジェスト再生

簡易ルールの架空試合：オフサイド・カード・PK・交代・厳密な接触物理は未実装。

## COURTSIDE（バスケ版）

`basketball/` に5対5の独立デモ。`http://localhost:5173/basketball/` で開く。

- 10分×4Q、24秒クロック、2点・3点、パス・ドリブル・スティール・リバウンド、ファウル/FTの簡易判定
- ゴール下に着いたら即フィニッシュ。フェイント→クロスオーバーでディフェンスを揺さぶり、逆側を抜くドライブ
- 上下対称バウンスの走行、加減速・方向転換に連動する体幹の傾き、選手ごとに異なる揺れのガード姿勢、ドライブ・スクリーン・ヘルプ等のチーム戦術
- 体幹は腰位置で回転し、走行時は前傾。腰の造形が体と脚をつなぎ、接続が自然に
- 細身の体型に胸ストライプ・ネックライン入りジャージ。選手名は漢字・カタカナ併記
- 実況（起こっているプレーの説明）と解説（プレーの意味・狙い、選手やチームの背景）を別の男性2音声で分担。実況・解説ともセリフのバリエーションを拡充
