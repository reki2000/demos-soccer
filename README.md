# TOUCHLINE

JavaScript + Three.js / WebGL による、22人の3Dサッカーシミュレーター。

```sh
npm install
npm run dev
```

`npm run build` で静的配信用の `dist/` を生成します。`npm test` で試合ロジックとモデル・アニメーションの計算を検証します。

## 試合と操作

- 8か国・3スタジアム、各チームの 4-3-3 / 4-4-2 / 3-5-2 を選択
- バランス・ポゼッション・カウンター・ハイプレスを両チームに個別設定
- 初期カメラはボールに近い追従。中継・俯瞰・自由カメラに切り替え可能
- Space で一時停止、1/2/4倍速、リセット、全画面、試合統計・ミニマップ
- 日本語実況字幕は40場面×25表現の1,000パターン。選手名・国名・スコアを反映し、重要な場面を優先。CCボタンでオン／オフ
- 晴れ・曇り・雨・夕暮れを選択。東京のビル群、ロンドンの街並み、リオの山と海
- 左下に保持者（飛行中は最後に触れた選手）の名前・背番号・ポジション・年齢・身長・利き足・実際の移動速度

## 選手・演出

- 約7頭身のローポリ選手。架空の名前、個別の身長・体格・肌色・6種類の髪型
- 移動速度と歩幅を合わせた接地、膝・足首・肘の動き、走行速度に応じた体幹の前傾
- 選手ごとに判断時間をずらし、寄せ・カバー・マーク・サポート・走り込みを分担
- 競り合い、ボールを守る姿勢、ファウル時の転倒・起き上がり
- 長いパスの高い軌道、弱めのヘディング、胸・足のトラップ、トラップミス、ルーズボール
- 走り込む先を狙うパス。届かなければルーズボールになり、受け手へ自動転送しない
- ゴールキック・フリーキックは後退、構え、助走、キックの順で再開
- タッチラインを割ると短いスローイン。ファウル・コーナー・ハーフタイム・陣地交代
- 得点者をアップで追い、味方が並走して祝福。全員が陣地へ戻ってから再開
- 試合が止まるイベントは中央、プレー継続中のイベントは右上に表示
- キーパーの構え・手を伸ばす動き・キャッチとグローブ
- 得点後と試合終了時にスコアを中央表示。終了後は実際のシュート記録から最大10場面のダイジェストを自動再生（0.65倍速、近接カメラ、一時停止可）
- 芝・コンクリート・金属屋根・座席の手続き生成テクスチャ。スタンドの背面と床下・四隅は遮蔽
- 主審・副審2人、監督2人、ベンチの控え14人。服装・肌・髪・姿勢が異なる観客

1倍速で実時間1秒が試合時間12秒に相当します。90分は約7分30秒に再開待ち時間を加えた長さです。得点演出中は試合時計を止め、倍速設定によらず通常速度で演出します。国の変更は試合をリセットし、戦術・会場・カメラは即時反映します。

簡易ルールの架空の試合です。オフサイド・カード・PK判定・交代・厳密な身体接触物理は未実装です。ファウルは位置によらずフリーキックになります。実況は音声ではなく字幕で、状況別の実況句と追句を組み合わせた1,000種類です。ダイジェストは同じ試合の位置・姿勢・ボールを記録して再生し、結果の再計算はしません。

選手名・能力・スタジアムは実在の選手や会場の再現ではありません。WebGL 2 対応ブラウザが必要です。外部フォントを取得できない場合はシステムフォントへフォールバックします。


## COURTSIDE: バスケットボール版

同じリポジトリの [basketball/](./basketball/) に、独立した5対5の3Dバスケットボール・デモを追加しています。

- 開発サーバー起動後、http://localhost:5173/basketball/ を開いてください。
- チームは架空の4チームから選択。10分×4クォーター、24秒ショットクロック、2点・3点、パス、ドリブル、スティール、リバウンドを簡易シミュレーション。
- 中継・ボール追従・俯瞰・自由カメラ。Spaceで一時停止、1×/2×/4×、リセット、全画面、ミニマップ、試合統計に対応。
- 実時間1秒につき試合時計が8秒進行（1×の場合）。GitHub Pages では /basketball/ に配信されます。

ファウル、フリースロー、交代、厳密な歩数・3秒・8秒・アウトオブバウンズ判定は未実装です。試合は架空選手による簡易自動シミュレーションです。
